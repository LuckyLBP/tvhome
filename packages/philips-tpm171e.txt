# Packages on Philips TPM171E TVs running Android TV 8.0 (2017/2018 PUS and OLED
# series, TP Vision firmware). Read by scripts/debloat.sh.
#
# Tiers:
#   [safe]   ads, promo rows, telemetry, store demo. Verified off on a
#            65PUS8102/12 with the same platform and Android version, no crash
#            loops over standby and reboots.
#   [choice] works fine off, but you lose a feature. Asked one by one.
#   [keep]   never turned off. Listed so you know what they are.
#
# Checked against this TV on 2026-10-22 (PH7M_EU_5596, Android 8.0): every
# [safe] package marked "this TV" or without a note was present. Packages that
# dumpsys marks PERSISTENT are skipped by debloat.sh automatically.
#
# Sources: cleanyourtv examples/philips-65pus8102 (TPM171E, Android 8.0) and
# examples/philips-50pus8517 (Android 11), plus tv-detox docs/debloat.md.
# Package names differ between firmware builds; scripts/candidates.sh shows what
# your TV actually has. When in doubt, leave it on.
